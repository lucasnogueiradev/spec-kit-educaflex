# Contribuindo com o Spec-Kit Educaflex

Obrigado por considerar contribuir com o **Spec-Kit Educaflex**! 🎉

Este é um repositório voltado para a comunidade, criado por Lucas Nogueira. Nosso objetivo é criar a melhor base para Spec-Driven Development (SDD) integrado com Agentes de IA.

## Como posso contribuir?

Existem várias formas de contribuir para este projeto:

### 1. Reportando Bugs
Se você encontrou um bug ou o comportamento do motor divergiu do esperado, abra uma **Issue**. Por favor, inclua:
- Uma descrição clara do problema.
- Passos para reproduzir.
- A saída do terminal (se aplicável).
- O agente de IA que você estava utilizando (Antigravity, Claude, Cursor, etc).

### 2. Sugerindo Melhorias
Toda ideia é bem-vinda! Abra uma **Issue** explicando sua ideia de nova funcionalidade ou melhoria de usabilidade.

### 3. Contribuindo com Código
Se você deseja enviar código para corrigir um bug ou implementar uma nova funcionalidade:
1. Faça um **Fork** do repositório.
2. Crie uma branch para a sua feature (`git checkout -b feature/minha-feature-incrivel`).
3. Siga o fluxo do próprio motor: use `onp-spec` para guiar a sua implementação através do fluxo SDD. Nós amamos dogfooding!
4. Certifique-se de que os testes passam executando `npm test` e `npm run audit`.
5. Faça o commit (`git commit -m 'feat: adiciona minha feature incrivel'`).
6. Faça o push para a branch (`git push origin feature/minha-feature-incrivel`).
7. Abra um **Pull Request**.

## Código de Conduta

Nós nos baseamos no respeito mútuo. Por favor, seja gentil e colaborativo nas interações através de Issues e Pull Requests.
